Canonicalized Input Description:

- An integer a (1 ≤ a ≤ 1000)
- An integer b (1 ≤ b ≤ 10000)
- An integer n (1 ≤ n ≤ 100)

There are no more than 100 datasets.

### Example Input:

```
1 2 3
2 3 4
5 4 3
4 3 2
```
